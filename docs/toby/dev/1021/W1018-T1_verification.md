## 2026-10-23 已放置設備旋轉（歷史版本 783a943）

本節保留當時的實作與驗證結果；原先自行新增的 L1 action、測試及重疊拒絕行為已由 #79 的 L1 版本取代，不代表目前 PR 的差異或現行行為。2026-10-28 起，本 PR 僅提供 L2 旋轉入口，重疊仍可旋轉，完整結果見 [本次驗證紀錄](../1028/W1018-T1_L1_rotation_verification.md)。

正式畫布先前沒有註冊旋轉快捷鍵，原 rotateDevice 只作用於舊 editorStore，無法旋轉目前由 layoutStore 保存的設備。本次依後續需求補齊「點選已放置設備後按 R，順時針旋轉 90 度」，不是將旋轉回溯列為原 C1 工單的必要項。

- layoutStore 新增高階 rotateDevice action，沿用 Rotation 四向型別與既有佔格檢查。成功時一筆 MachineRotation Command；同角度不產生歷史，錯誤角度、缺失／重複 id 及重疊都不修改資料。Undo／Redo 可還原角度，管線保留原位。
- MainLayout 將既有單選 id 傳給 LayoutView，並以既有 resolveDisplayGrid 更新左側面板尺寸，沒有另建第二份選取狀態。
- LayoutView 使用 onComboTriggered 的 rotateDevice 動作，預設 R 並支援改鍵及長按去重。沒有選取、文字輸入、平移工具、手勢中或快捷鍵設定面板開啟時不旋轉。
- 拒絕旋轉時透過既有狀態文字顯示原因；埠、長寬、衍生連線與斷線驚嘆號依目前設備資料自動更新。
