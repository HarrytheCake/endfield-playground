# 正式畫布支援埠連線與設備旋轉

正式畫布原先只能拖設備與平移，無法從埠建立管線。現在一般左鍵會優先命中埠，顯示本地 draft 與目標 highlight，放開時使用 canConnect、端點身分比對及既有碰撞檢查驗證，再透過 addPipeline 提交一次。非法路徑改紅色預覽，放開後清除並顯示非彈窗回饋。

draft 僅存在 LayoutView 的 local ref，取消、失去捕捉與卸載皆清理；埠幾何與機型映射由 L2 轉成 props，GridCanvas 只呈現埠點、預覽與狀態文字。保留設備拖曳、空白／中鍵／pan 平移及連續落子，新增程式附繁體中文 JSDoc，顏色使用 Tailwind 內建色階。

單轉角與設備空隙雙轉角由 `src/utils/layout/connectionWaypoints.ts` 的純函式生成；LayoutView 僅映射輸入、呼叫並串接既有預檢。純函式不讀取 store，也不搜尋繞過第三台設備或既有管線的路徑。

斷線端點由既有 layoutStore.connections 判定，透過 props 掛上其他作者提供的 WarningIcon，重新接回即清除。依使用者要求，埠命中只限可見圓點，取消附近熱區；GridCanvas.stories.ts 維持 Git 基準內容。

## 設備旋轉（串接 #79）

已放置設備可在選取後以預設 R 鍵順時針旋轉 90 度，並支援既有鍵位設定。LayoutView 呼叫 aaaaa 在 #79 提供的 `layoutStore.rotateDevice`，由 L1 自行建立歷史；原點與管線保留原位，重疊仍允許旋轉，由 layoutIssues 提供 E001 重疊資料。MainLayout 與 LayoutView 共用同一個選取 id，旋轉後尺寸、埠及斷線警示同步更新。文字輸入及拖曳時不觸發旋轉。本 PR 不修改 L1 action 或其契約測試。

正式頁既有 useValidation 監聽 editorStore，尚未在此 PR 接入 layoutStore.layoutIssues 的 E001 畫面提示；斷線驚嘆號則獨立取自 layoutStore.connections。
