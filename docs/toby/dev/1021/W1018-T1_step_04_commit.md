# W1018-T1 步驟 04 放開驗證與提交

狀態：已驗證。日期：2026-10-21。[步驟索引](./W1018-T1_steps.md)。

## 目標與檔案

在 LayoutView 依命中 PortRef 查外側錨點，優先建立直線或單一正交轉角，呼叫 canConnect 與 assessInvolving，再於正常 pointerup 呼叫 addPipeline。2026-10-23 修正：若原走線只穿過端點設備，平行埠可改用兩設備間空隙的固定雙轉角。

## 限制

不改 L1 規則，不自行建立 Command，不做自動繞障。canConnect 成功時還要比對實際解析的兩端；action 回傳失敗仍需處理。錯誤文字透過 prop 交由展示層呈現。

## 驗收結果

合法 belt 與 pipe 連線各恰一次提交與一筆歷史；pipe 端點使用 z=1。方向、媒質、自連、埠佔用、碰撞與同格錨點解析到其他埠皆拒絕，未命中不寫入。正交轉折案例通過。

2026-10-23 補驗證並排塑型機、非正方灌裝機四方向旋轉與正式工具列放置後的連線；空隙存在第三台設備或既有線時仍拒絕。根因與座標例子見 [修正紀錄](./W1018-T1_verification.md#2026-10-23-生產設備連線修正)。
