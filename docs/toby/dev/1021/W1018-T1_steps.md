- [x] 確認分支與工作目錄狀態，以目前 `dev/toby` 的本機內容為基準；本次未 pull 或合併遠端。
- [x] 閱讀 `LayoutView` 現有 pointerdown／move／end、clearGesture 及 click 抑制流程。

## 步驟二 補上埠顯示與連續座標命中

分步文件：[步驟 02](./W1018-T1_step_02_ports.md)。

- [x] 用既有機型 mode、旋轉及埠定位工具產生視覺埠點，處理不同 rotation／mode。
- [x] 讓 `GridCanvas` 透過 props 顯示埠與 hover／目標 highlight，維持無 Pinia。
- [x] 在容器增加保留小數的指標座標換算，保留原有整數格換算供拖設備使用。
- [x] 依使用者 2026-10-23 的選擇，呼叫 `hitTestPortAt` 時將命中半徑限制在可見圓點，取消附近熱區；L1 預設值不修改。
- [x] 確認平移與縮放後，埠點與命中熱區仍一致。

完成條件：游標位於可見圓點內才高亮或起拖拉線；圓點附近仍判斷為設備體或空白。

## 步驟三 加入本地 draft 手勢

分步文件：[步驟 03](./W1018-T1_step_03_draft.md)。

- [x] 擴充手勢種類，保留中鍵與 pan 工具的既有行為。
- [x] 一般左鍵先判斷埠，再判斷設備體與空白，按下時固定手勢種類。
- [x] 使用 `LayoutView` local ref 保存來源埠、游標位置、目標埠及必要預覽資料。
- [x] 移動時更新 draft 與目標 highlight，透過 props 交給 `GridCanvas` 畫線。
- [x] 拉線期間不呼叫任何寫入 layout 或 history 的 action。
- [x] 抑制拉線後的 click，避免觸發落子或選取副作用。

完成條件：按住埠能拉出跟隨游標的線，設備拖曳與空白平移仍可操作。

## 步驟四 放開驗證與提交

分步文件：[步驟 04](./W1018-T1_step_04_commit.md)。

- [x] pointerup 消費最後座標，重新確認目標命中，未命中直接清除 draft。
- [x] 依 PortRef 查來源與目標外側錨點，不能使用視覺埠點或滑鼠取整結果代替。
- [x] 建立 media 與軸對齊 waypoints；先完成直線案例，需要時再加入明確正交轉折。
- [x] 呼叫 `canConnect`；確認 ok 且 from／to 對應實際選取的兩個埠。
- [x] 起拖時只配置本地管線 id，合法放開後呼叫 `layoutStore.addPipeline` 一次，並處理其失敗回傳。
- [x] 非法連線不提交，不彈窗；可用紅色預覽或短提示回饋。
- [x] 成功或失敗皆清除 draft；只有成功提交才新增管線與歷史。

完成條件：合法 port 對 port 放開後管線留下，非法或未命中不寫入。

## 步驟五 清理與互動回歸

分步文件：[步驟 05](./W1018-T1_step_05_regression.md)。

- [x] pointercancel、lostpointercapture、元件卸載均清除 draft，不提交。
- [x] 保留 pointerId 與起始按鍵檢查，其他指標或按鍵不會提早提交。
- [x] 清除手勢時先重設本地狀態，再釋放捕捉，避免重入。
- [x] 檢查捕捉後在畫布外放開的情境，不會誤連或意外落子。
- [x] 檢查拉線中使用既有鍵盤平移時，預覽與命中不會使用過期座標。

| 操作                        | 預期結果                              |
| --------------------------- | ------------------------------------- |
| 合法輸出埠拖到相容輸入埠    | 目標 highlight，放開新增一條管線      |
| 拖到空白或未命中            | draft 消失，佈局與歷史不變            |
| 輸出接輸出或輸入作起點      | 拒絕提交                              |
| 不同媒質、自連、已佔用埠    | 拒絕提交                              |
| 路徑穿越設備或同層既有管線  | 依 addPipeline 檢查拒絕，不留下 draft |
| 按設備體拖曳                | 維持設備移動                          |
| 拖空白、中鍵或 pan 工具     | 維持原平移行為                        |
| 工具列已選機器後完成拉線    | 不因後續 click 多放一台設備           |
| 不同旋轉與 mode、平移及縮放 | 埠視覺、熱區與錨點一致                |
| 取消、失去捕捉或離開頁面    | 不提交、不留預覽殘影                  |
