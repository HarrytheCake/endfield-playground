## 0. 先記這一句

滑鼠點得到，不代表管子能接在那個小數點上。  
滑鼠問的是埠旁邊的圓形範圍。管子問的是機器外面那一個整數格。

---

## 1. 怎麼自己看

```bash
pnpm dev
# 左側「L1 契約實驗室」，或直接 /dev/l1-contract-lab
# 點「試玩」
```

1. 「要問的問題」選 **滑鼠有沒有點到埠**。
2. 點範例 **點在進料口旁邊**。綠色框應寫：有點到機器 c 的第 1 個進料口。
3. 改選 **這個格子能不能接管子**，再點 **拿滑鼠的點去對端點**。綠色框應寫：沒有對上。同一組小數，滑鼠算點到，管子不算接在那裡。
4. 頁面最下方的 JSON 是同一題的完整資料。先讀 `plain` 那一句即可。

機器是固定的，不能在這頁換機型。下面的格子表只能看，那是接管子用的整數格，不是滑鼠的圓心。

---

## 2. 給拉線的人

| 你在做 | 用哪一支 | 不要 |
|--------|----------|------|
| 滑鼠按下、拖、放開 | 滑鼠那支（程式名 `hitTestPortAt`） | 不要改用整數格那支當滑鼠 |
| 判斷管子端點落在哪一格 | 整數格那支（程式名 `findPortAt`） | 不要把滑鼠的小數點存成管子端點 |
| 兩個埠疊在同一個點 | 拉線起點優先出料，放開優先進料 | 不指定時，結果會跟著機器的排列順序變 |

正式畫布的接法沒有因這頁改動。`LayoutView`、`GridCanvas`、store 簽名都沒動。

---

## 3. 這刀沒有交給你的

- 還沒有「這條線能不能接」的試玩（`canConnect`）。規則仍看 V14 的一鍵案例。
- 不是一張可以呼叫所有函式的表。
- 不發解鎖句。右側產耗、供水、設備外形都不是這頁的事。
