## 1. 這個任務要解決什麼

`00_top_spec.md` 目前嵌的兩張畫面示意圖（`mockup_main_screen.svg` / `mockup_flow_view.svg`），是**低保真線框稿**——只是把 spec 要求的功能區塊用程式碼畫出色塊示意各區域放什麼、大概多大，完全不是正式的視覺設計（顏色、字體、間距、資訊層級都只是隨手選的）。這次任務就是請你依照這兩張線框稿標示的功能區塊與 spec 文字敘述，設計出正式的視覺稿：

1. **佈局視角**（對應 `mockup_main_screen.svg`）
2. **流程視角**（對應 `mockup_flow_view.svg`）

這次**只需要做這兩張畫面的視覺設計**，不需要做其他頁面（獨立優化頁、匯出記錄檔頁面等）、不需要做互動原型或前端實作。

## 2. Spec 依據——每張畫面要涵蓋的功能區塊

### 2.1 佈局視角（`01_canvas_and_devices.md` + `11_toolbar.md`）

- **格子畫布**：精確格線，設備依佔格數擺放；可選擇性疊加基地框線（武陵 / 四號谷地）
- **物件資訊面板**：點選設備時顯示，內含三個 Tab——「配方表」「設備形狀」「耗電與資訊」
- **下方設備工具列**：依分類（採集 / 加工 / 種植 / 電力 / 物流 / 儲存）Tab 切換、每個設備顯示圖示＋名稱、搜尋框
- **產線總覽面板**（右側常駐）：總耗電量／供電量、產能估算、警示列表（Error / Warning）
- **視角切換控項**：左下角，佈局／流程／（Phase 2 並列）
- **框選 / 多選視覺**、**復原重做按鈕**、**縮放顯示**
- **設備擺放視覺回饋**：綠色半透明＝可放置預覽、紅色半透明＝重疊警示（見 CR-03 §2.3：Error 紅框＋⚠️ 圖示、Warning 黃框＋⚠️ 圖示，管線 Error 紅色閃爍框、Warning 黃色框）

### 2.2 流程視角（`05_recipe_flow.md`）

- **Flow Chart 節點四種類型**，各有指定樣式方向（可依此為基礎再設計，非強制照抄）：
  - 原料節點：圓角矩形
  - 設備節點：矩形，顏色依效率分級（綠／黃／橘／灰）
  - 產物節點：橢圓
  - 倉庫節點：橢圓＋虛線邊框
  - 待導入節點（Phase 2）：矩形＋虛線＋半透明
- **邊（連線）**：顯示品項名稱與流量（個/min），自左向右排列（原料 → 設備 → 產物）
- 右側**產線總覽面板**、左側**物件資訊面板**與佈局視角共用同一容器概念，但顯示內容對應「節點」而非「設備」
- 左下角視角切換控項（與佈局視角同一元件，樣式一致，只是選取狀態不同）
- **Phase 1 範圍**：只需設計「佈局／流程」二態切換；「並列視角」「新增流程配方」「一鍵導入」是 Phase 2 功能，**不用**在這次的視覺稿裡處理，如果想預留視覺空間可以口頭註記但不用細化

## 3. 已有的東西 / 限制條件

- **目前沒有任何正式設計系統**：`src/assets/styles/tokens.css`（依 `CLAUDE.md` 規範，自訂顏色最終都會統一寫在這裡）目前還不存在，你這次的設計稿等於是在定義這個色彩系統的起點
- **技術框架**：畫面最終會用 **Nuxt UI v4 + Tailwind CSS** 實作，元件優先使用 Nuxt UI 內建元件（Button、Modal、Table、Tooltip、Tabs 等）。設計時建議先看一下 [Nuxt UI 官方元件庫](https://ui.nuxt.com/) 的視覺語言與可用元件範圍，避免設計出 Nuxt UI 元件庫做不到、之後開發要另外刻的東西
- 現有兩張線框稿是深色主題，但**這不是最終決定**，你可以沿用深色方向或提出更好的方案，兩者皆可
- 遊戲原生的設備圖示 / 素材來源尚未決定（`00_top_spec.md` §6「待確認事項」第 1 點：自繪 SVG 或遊戲截圖，需考量版權），這次設計稿可以先用色塊 / 幾何圖形佔位，不用等圖示素材到位

## 4. 驗收標準

1. 兩張畫面（佈局視角、流程視角）的高保真視覺稿，涵蓋第 2 節列出的所有功能區塊
2. 兩張畫面的視覺語言一致（配色、字體、間距系統、圓角規則等共用同一套）
3. 清楚呈現 Error / Warning 的視覺樣式（設備紅框 / 黃框 + ⚠️ 圖示、管線紅色閃爍框 / 黃色框），讓後續開發者知道具體顏色數值
4. 流程視角的四種節點類型（原料 / 設備 / 產物 / 倉庫）與效率分級（綠 / 黃 / 橘 / 灰）視覺區分清楚
5. 產出格式不限（Figma 連結、匯出圖片皆可），放入 `docs/paper/` 或提供連結即可，後續會由開發者依此稿實作 L3 元件
