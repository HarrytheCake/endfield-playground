# 0726 程式碼建議

## 整體上看得出來你有好好在學 Vue 的寫法，也看的出來這個不是只讓 AI 生的東西

## 但有些比較大的問題需要跟你說

1. 一個 Vue 檔案中，理應只有一個 `<template>`、一個 `<script>`、一個 `<style>`

    如果有多個，你無法確認到底會執行到哪一個。

2. 在你每次覺得 code 寫的 OK 之後，你都得要執行一次 pnpm 指令中的 `validate-all`

    他在 vs-code 檔案總管列的最下面下拉表單 `NPM 指令碼` 展開中，找到他點一下 play 就會執行了。  
    他會執行所有程式碼靜態檢查，確保你符合我們整個專案的程式碼基礎規範。

3. 在第 35 行，你疑似嘗試引用這個檔案自身

    感覺你這個檔案之後應該是會放到 `src/components/` 中的，那這樣就代表你會引用到自己這個檔案，產生循環引用，那程式是執行不起來的。
