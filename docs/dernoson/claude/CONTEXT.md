# CONTEXT

本文件統整專案中的專有名詞與核心概念，僅提供簡述與定位；詳細規格請見對應 CR 條目與 Feature Spec 檔案（`spec/`）。

---

## 1. 視角與畫面名詞

- **藍圖（Blueprint）**：匯出 / 匯入的記錄檔本體。→ CR-06
- **佈局視角**：設備擺放、旋轉、管線連接的編輯畫面。→ CR-01、CR-02
- **流程視角**：Flow Chart 呈現產物流向、設備、效率與配比。→ CR-05
- **並列視角**：佈局視角與流程視角並排顯示，兩者選取 / 編輯即時聯動。→ CR-05

---

## 2. 產線物件名詞

- **管線**：連接設備接口的線路，依物料型態分傳送帶（固體）／水管（液體 / 氣體）。→ CR-01、CR-02
- **供電樁**：具 N×N 方形供電範圍的設備，範圍內（部分即可）的設備才會運作並耗電。→ CR-10

---

## 3. 部署動作

- **部署**：將配方流程設計（CR-05 Phase 2）或多目標優化結果（CR-07）轉為佈局視角中一串**初始佈局**，供使用者後續編輯優化。→ CR-05、CR-07

---

## 4. 資訊面板

- **物件資訊面板**：點選設備 / 管線時顯示的左側面板，內容依物件類型而異。→ CR-01、CR-02、CR-03、CR-11
- **產線總覽面板**：右側恆常顯示的整條產線層級概覽（產能、耗電、警示等）。→ CR-03、CR-04

---

## 5. 警示系統分類

警示分為擺設衝突類（CR-03）、流量 / 配方警示類（CR-09）、電力警示類（CR-10 警示部分）三大類，共用 Error / Warning 兩種嚴重等級與顯示規格（不阻擋操作、於相關物件標示、於資訊面板列出）。詳細觸發時機與各項警示內容見對應 CR。
