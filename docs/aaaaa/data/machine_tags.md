# machine_tags.json — 機器標籤清單

根節點：`string[]`。

機器分類用標籤字串列表，供機器編輯 UI 多選。與 `machines[].tags` 為軟關聯（慣例上 tags 應出現在此清單，程式不強制外鍵）。

---

## 格式

```json
[
  "物流設備",
  "倉庫存取",
  "基礎生產",
  "合成製造",
  "電力"
]
```

| 約束 | 說明 |
|------|------|
| 元素 | 非空字串 |
| 唯一 | 建議去重；順序可當 UI 顯示序 |

---

## 轉換注意

- 可從所有 `machines[].tags` 聯集重建本檔。
- 轉換目標若不需要分類 UI，可省略本檔，只保留機器上的 `tags` 陣列。
