## 新增依賴與開發用指令
新增了 pnpm 指令 `validate-all`，你可以隨時執行這個，他會同時跑 format、lint、type-check、test，在 push 出來前都能執行一下，就能保證 merge 時檢查能過關了。
那麼這個工具有一個新的套件得要裝，你可以在 terminal 輸入 `pnpm i` 更新安裝。

## AI skill 與 prompt
有在使用 AI 的，歡迎隨時使用 `docs/dernoson/claude` 中的東西
* agent: 固定要做什麼事的規劃
  * test: 專門幫你寫測試的
  * grapher: 專門幫你畫模組依賴圖的
* skills: 當你跟 ai 的對話出現關鍵字就會觸發的動作
  * add-jsdoc: 幫你寫符合我們慣例的模組功能註解
* CLAUDE.md: 大規範，講述我們寫 code 的慣例，告訴 ai 能做什麼不能做什麼。

## 如何跟上目前的進度
1. 確認自己的 branch 的東西都已經 commit 完畢
2. 右下角切換到 master branch
3. terminal 輸入 `git pull --prune`
4. 切換回自己的 branch
5. terminal 輸入 `git merge master`
6. 如果有 conflict，告訴我，我教你處理
