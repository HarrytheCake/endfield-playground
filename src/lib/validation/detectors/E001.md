Question:
Given a map and some objects, how to find all the pairs that overlap with each other
(all the numbers are int and positive if u really need)
## Version: 2026/06/07

## Target
find all the objects that overlap each other

---

## Primitive: overlap check

### Define "overlap"
Two objects overlap if and only if their projection intersect on **all** dimensions.
```
function overlap(obj1, obj2) -> bool
{
    d from 1 to dim:
    {
        if (obj1.x_{d} + obj1.wid_{d} <= obj2.x_{d} || obj2.x_{d} + obj2.wid_{d} <= obj1.x_{d})
        {
            return false;   // separated on this axis → no overlap
        }
    }
    return true;        // not separated on any axis → overlap
}
```
Execute $dim$ times per pair.

## Algorithm: Chunk-based broad phase

### Notation
| Symbol | Meaning |
|---|---|
| $dim$ | dimension (likely 2, since $z$-axis is thin) |
| $M$ | map size (per axis) |
| $N$ | number of objects |
| $s$ | avg object size (per axis) |
| $C$ | chunk size (per axis) |

Moreover, we may assume $C>s$
```
class object 
{
    id: string or int;
    position: [x_{1},...,x_{dim}][min,max];
    // dim x 2 array
}
```

---

### Step 1.1 — Distribute objects into chunks

```
i from 1 to N:
{
    d from 1 to dim:
    {
        cmin_{d} = floor(object[i].x_min_{d} / C)
        cmax_{d} = floor(object[i].x_max_{d} / C)
        // 0 <= cmax_{d} - cmin_{d} <= 1
    }

}
```

### Step 1.2 — Some objects may cross chunks
