# Feature Spec：流量模擬與產能估算
# CR-04

- **所屬階段：** Phase 1（基礎估算）/ Phase 2（調度券效率）
- **依賴：** CR-01（設備與配方定義）、CR-02（管線連接狀態）、CR-03（警示狀態，決定哪些節點略過）、CR-10（供電範圍與耗電量計算結果，用於產線總覽面板電力狀態顯示）
- **文件版本：** v0.3

---

## 1. 功能定位

FlowEngine 是模擬器的核心計算模組。每當畫布狀態變動，即時以靜態流量分析計算整條產線的穩態產能，並在畫布上與產線總覽面板即時呈現結果。有 Error 的設備與管線略過計算，不影響其餘正常節點的估算。

---

## 2. 功能詳細描述

### 2.1 觸發時機

以下任一事件後，FlowEngine 自動重新計算（debounce 處理避免高頻觸發）：
- 設備擺放、移動、刪除、旋轉
- 管線新增、刪除、修改
- 設備配方變更

### 2.2 計算範圍

- 有 Error 等級警示的設備與管線**略過**計算（Error 判定詳見 CR-03、CR-09）
- 略過的節點在畫布上顯示為灰色（無流量標示）
- 其餘連通的子圖各自獨立計算

### 2.3 計算方式：靜態流量分析

採**有向圖拓撲排序**後正向傳播計算，假設穩態滿產情況：

1. 建立有向圖：節點為設備，邊為管線（含方向）
2. 拓撲排序（若偵測到環路則標記為異常，略過該子圖）
3. 從 source 節點（礦機、種植機等無輸入接口的設備）開始，依拓撲順序正向計算各邊流量
4. 限流規則：若輸入速率 < 配方需求速率，以輸入速率為上限等比縮放輸出
5. 分流器：輸入流量平均分配至各輸出（或依使用者設定的分流比例）
6. 匯流器：各輸入流量加總後輸出

**流量單位：** 個 / 分鐘

### 2.4 畫布即時顯示

計算完成後，在以下位置顯示流量數值：

- **管線上**：顯示當前傳輸速率（個/min），懸停時顯示詳細 tooltip
- **設備上**：顯示當前運行效率（%）
- **產線起點（source）**：顯示總輸出速率
- **產線終點（sink，取貨口）**：顯示總收入速率

**效率顏色編碼：**
- 100%：綠色
- 50%–99%：黃色
- 0%–49%：橘色
- 0%（完全無輸入）：灰色

### 2.5 產線總覽面板

#### 整體統計區塊
```
總耗電量：    XXX kW
總供電量：    YYY kW
電力狀態：    ✅ 盈餘 ZZZ kW  /  ⚠️ 不足 ZZZ kW（對應 W005）

設備數量：  XX 台（含 X 台有 Error）
管線數量：  XX 條
```

#### 產出摘要表
依品項列出生產 / 消耗 / 淨產量與效率：

| 品項 | 生產（/min） | 消耗（/min） | 淨產量（/min） | 效率 |
|------|-------------|-------------|---------------|------|
| 紫晶纖維 | 4.0 | 4.0 | 0.0 | 100% |
| 工業爆炸品 | 2.0 | — | +2.0 | 100% |
| 穩定碳塊 | 1.5 | 2.0 | -0.5 | ⚠️ 75% |

- 淨產量為正：綠色（盈餘）
- 淨產量為負：紅色（不足，上游供料不足以滿足下游需求）

#### 調度券兌換效率（Phase 2）

使用者在設定區自訂各品項的調度券兌換率（個/min → 券/hr），面板顯示：

```
調度券預估產出：XXX 券/hr
  └ 工業爆炸品 × 2.0/min → YY 券/hr
  └ 穩定碳塊 × 1.5/min   → ZZ 券/hr
```

## 3. 驗證方式

| 驗證項目 | 方法 |
|----------|------|
| 即時重算觸發 | 擺放設備後確認管線與面板數值即時更新（< 200ms） |
| 管線變動觸發重算 | 新增、刪除或修改管線後，確認流量與效率即時重新計算 |
| 配方變更觸發重算 | 變更設備運行配方後，確認下游流量依新配方重新計算 |
| Source 到 Sink 正確傳播 | 建立簡單單條產線，確認各節點流量與配方速率一致 |
| 限流縮比 | 礦機供料不足配方需求，確認效率顯示對應比例而非 100% |
| 環路偵測 | 建立含環路的管線連接，確認該子圖被標記為異常並略過計算，不影響其他子圖 |
| 分流器均分 | 接入分流器後確認兩側輸出各為輸入的一半 |
| 匯流器加總 | 多條管線接入匯流器，確認輸出流量為各輸入流量加總 |
| Error 節點略過 | 製造 E001 重疊，確認重疊設備不顯示流量，其下游也顯示灰色 |
| 效率顏色分級 | 分別製造 100%／50%–99%／0%–49%／0%（無輸入）四種效率情境，確認設備顏色對應為綠／黃／橘／灰 |
| 電力統計 | 擺放供電樁與耗電設備，確認產線總覽面板總耗電量與總供電量數值正確，盈餘 / 不足狀態正確顯示 |
| 產出摘要表 | 確認生產 / 消耗 / 淨產量計算正確，負值顯示紅色 |
| 調度券計算（Phase 2） | 設定兌換率後確認預估券數即時更新 |
