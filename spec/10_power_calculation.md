# Feature Spec：產線電力計算
# CR-10

- **所屬階段：** Phase 1（計算）/ Phase 2（Warning）
- **依賴：** CR-01（設備擺放狀態，含供電樁本身）、CR-03（沿用其定義的 Error / Warning 顯示規格與面板呈現慣例）
- **文件版本：** v0.3

---

## 1. 功能定位

電力模組持續監聽畫布狀態與供電樁佈局，計算設備供電範圍與整區耗電量，並偵測相關問題以 Warning 回饋給使用者。計算結果供 CR-04 產線總覽面板顯示電力狀態。

---

## 2. 功能詳細描述

### 2.1 觸發時機

以下任一狀態變更後，自動重新執行計算與驗證：
- 設備擺放、移動、刪除

計算與驗證採同步方式，結果即時更新至 store，不需使用者手動觸發。

### 2.2 供電範圍與耗電量計算

- 供電樁具有 N×N 方形供電範圍，範圍大小由設備定義決定
- 取所有已擺放供電樁的供電範圍聯集；設備任一格落在聯集內即視為供電成功
- 設備須部分處於供電樁範圍內才會運作，並耗用該設備設定的耗電量；完全處於範圍外的設備不耗電、不運作
- 基地模式下不允許擺放中繼器，供電覆蓋僅由供電樁決定
- 總供電量由使用者自訂；未設定時視為無限供電，不觸發總量超載判斷
- 計算結果（總耗電量、總供電量、各設備供電狀態）供 CR-04 產線總覽面板顯示，以及本文件 2.3 警示判斷使用

### 2.3 警示等級定義

#### Warning（不阻斷估算）
Warning 不影響流量估算，僅提醒使用者注意潛在問題。

| 代碼 | 名稱 | 觸發條件 |
|------|------|----------|
| W004 | 設備未供電 | 該設備完全處在供電樁範圍外 |
| W005 | 總耗電量超過本區域供電量 | 使用者自訂該區總供電量時，所有處在供電樁範圍內設備的總計耗電量超過供電量 |

### 2.4 畫布視覺警示

#### 設備層級
- **Warning**：設備邊框顯示黃色，並在角落顯示 ⚠️ 圖示

### 2.5 物件資訊面板顯示

點選有電力警示的設備時，物件資訊面板列出該物件當前所有警示項目（代碼與說明），與畫布上的黃色高亮同步呈現。

### 2.6 產線總覽面板警示列表

產線總覽面板包含獨立的警示列表區塊：

```
⚠️ Warnings (2)
  [W004] 設備未供電：電驅礦機 #5
  [W005] 總耗電量超載：需求 120 kW，供給 100 kW
```

**點選任一警示項目：**
- 畫布自動導覽（Pan + Zoom）至相應設備
- 相應元素閃爍高亮 1.5 秒

## 3. 驗證方式

| 驗證項目 | 方法 |
|----------|------|
| W004 設備未供電 | 擺放設備但不在任何供電樁覆蓋範圍內，確認出現 W004 黃色警示 |
| 部分重疊視為供電成功 | 擺放設備使其僅部分格子落在供電樁範圍內，確認不觸發 W004 且該設備正常運作耗電 |
| W004 供電覆蓋聯集 | 擺放兩個供電樁覆蓋不同區域，確認兩區域的設備均不出現 W004 |
| W004 供電樁移動即時重新評估 | 移動已擺放供電樁，確認範圍變化後受影響設備的 W004 即時更新 |
| 未供電設備不耗電 | 設備完全處於供電樁範圍外，確認其耗電量不計入總耗電量加總 |
| 耗電量加總 | 擺放多台供電範圍內設備，確認總耗電量為各設備耗電量正確加總 |
| 未設定總供電量 | 不設定該區總供電量，確認無論耗電量多高都不觸發 W005 |
| W005 總耗電超載 | 耗電量超過總供電量，確認出現 W005 黃色警示 |
| 物件資訊面板顯示警示 | 點選有警示的設備，確認物件資訊面板列出對應代碼與說明 |
| 點選警示導覽 | 點選警示列表項目，確認畫布平移至相應設備並閃爍 |
| 警示即時更新 | 修正供電問題後，確認 W004 即時從列表消失 |
