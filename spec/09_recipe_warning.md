# Feature Spec：產線流量計算 - 配方警示
# CR-09

- **所屬階段：** Phase 1（Error）/ Phase 2（Warning）
- **依賴：** CR-01（設備配方狀態）、CR-02（管線連接狀態）、CR-03（沿用其定義的 Error / Warning 顯示規格與面板呈現慣例）、CR-04（輸入不足 / 輸出阻塞需依賴流量估算結果判斷）
- **文件版本：** v0.3

---

## 1. 功能定位

警示模組持續監聽畫布狀態與設備配方設定，偵測配方輸入輸出與管線流量相關的問題，分 Error 與 Warning 兩級回饋給使用者。警示狀態同時影響 CR-04 流量估算的計算範圍（有 Error 的節點略過）。

---

## 2. 功能詳細描述

### 2.1 警示觸發時機

以下任一狀態變更後，自動重新執行全局驗證：
- 管線新增、刪除、修改
- 設備配方變更

驗證採同步計算，結果即時更新至 store，不需使用者手動觸發。

### 2.2 警示等級定義

#### Error（阻斷估算）
有 Error 的設備或管線會被 CR-04 流量估算略過，不參與計算。

| 代碼 | 名稱 | 觸發條件 |
|------|------|----------|
| E004 | 輸入缺失 | 設備配方明確要求輸入時，未接入任何輸入（含部分輸入缺失，可能有多種輸入） |
| E005 | 輸出缺失 | 設備配方明確要求輸出時，未接出任何輸出（含部分輸出缺失，可能有多種輸出） |

#### Warning（不阻斷估算）
Warning 不影響流量估算，僅提醒使用者注意潛在問題。

| 代碼 | 名稱 | 觸發條件 |
|------|------|----------|
| W001 | 材料組合無法處理 | 設備輸入材料組合不符配方，無法被該設備任一配方使用（可能有多種輸入材料） |
| W002 | 輸入不足 | 管線輸入端流量不足以滿足下游所需；含輸入端缺失（此時輸入端流量視為 0） |
| W003 | 輸出阻塞 | 管線輸出端無法排出全部流量；含輸出端缺失（此時輸出端流量視為 0） |

### 2.3 畫布視覺警示

#### 設備層級
- **Error**：設備邊框顯示紅色，並在角落顯示 ⚠️ 圖示
- **Warning**：設備邊框顯示黃色，並在角落顯示 ⚠️ 圖示
- 同時有 Error 與 Warning 時，以 Error 樣式優先顯示

#### 管線層級
- **Error**：管線顯示紅色閃爍邊框
- **Warning**：管線顯示黃色邊框
- 懸停管線時 tooltip 顯示警示代碼與說明

### 2.4 物件資訊面板顯示

點選有配方警示的設備或管線時，物件資訊面板列出該物件當前所有警示項目（代碼與說明），與畫布上的紅 / 黃色高亮同步呈現。

### 2.5 產線總覽面板警示列表

產線總覽面板包含獨立的警示列表區塊，依 Error → Warning 排序：

```
⛔ Errors (1)
  [E004] 輸入缺失：混合機 #2 輸入接口 (input_0) 無管線連入

⚠️ Warnings (2)
  [W001] 材料組合無法處理：電驅礦機 #2 輸入品項不符任一配方
  [W003] 輸出阻塞：管線 #4 輸出端無法排出全部流量
```

**點選任一警示項目：**
- 畫布自動導覽（Pan + Zoom）至相應設備或管線
- 相應元素閃爍高亮 1.5 秒

## 3. 驗證方式

| 驗證項目 | 方法 |
|----------|------|
| E004 輸入缺失 | 設備配方要求輸入但不接任何管線，確認出現 E004 紅框 |
| E005 輸出缺失 | 設備配方要求輸出但不接任何管線，確認出現 E005 紅框 |
| W001 材料組合無法處理 | 將輸出品項 A 的設備接入需要品項 B 的設備，確認出現 W001 黃色警示 |
| W002 輸入不足（Phase 2）| 上游管線流量不足以滿足下游所需，確認出現 W002 黃色警示 |
| W003 輸出阻塞（Phase 2）| 管線輸出端流量持續超過可排出上限，確認出現 W003 黃色警示 |
| Error 略過估算 | 製造 E004，確認該設備不出現在流量估算結果中 |
| 設備配方變更觸發重新驗證 | 變更設備運行配方後，確認即時重新驗證並依新配方判斷警示 |
| 管線 tooltip 顯示警示 | 懸停有警示的管線，確認 tooltip 顯示警示代碼與說明 |
| Error 與 Warning 同時顯示優先權 | 令設備同時觸發 E004 與 W001，確認以紅色 Error 樣式優先顯示 |
| 物件資訊面板顯示警示 | 點選有警示的設備，確認物件資訊面板列出對應代碼與說明 |
| 點選警示導覽 | 點選警示列表項目，確認畫布平移至相應設備並閃爍 |
| 警示即時更新 | 修正輸入缺失問題後，確認 E004 即時從列表消失 |
