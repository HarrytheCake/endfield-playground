# Feature Spec：操作歷史
# CR-08

- **所屬階段：** Phase 1
- **依賴：** CR-01（設備擺放 / 移動 / 旋轉 / 刪除 / 複製 / 配方變更等操作納入歷史）、CR-02（管線新增 / 移動 / 複製 / 刪除 / 彎折點修改等操作納入歷史）、CR-05（流程視角配方節點新增 / 刪除、中間產物設定變更納入歷史）
- **文件版本：** v0.3

---

## 1. 功能定位

操作歷史模組以 Command Pattern 統一管理所有佈局狀態變更，提供無限制的復原 / 取消復原功能。CR-01、CR-02、CR-05 的所有操作均透過本模組提交，任何視角下的 Ctrl+Z / Ctrl+Y 均作用於同一歷史佇列。Session 結束後歷史清空，不持久化至 localStorage。

---

## 2. 功能詳細描述

### 2.1 復原 / 取消復原

- **Ctrl+Z**：復原上一步操作，還原 Pinia store 至操作前狀態
- **Ctrl+Y**：取消復原，重新套用已復原的操作
- 無步驟數限制
- 在任何視角（佈局 / 流程 / 並列）均可觸發，作用於同一歷史佇列
- 執行新操作後，取消復原佇列清空（標準行為）

### 2.2 納入歷史的操作範圍

以下操作均須納入操作歷史，可被復原 / 取消復原：

**CR-01 設備擺放：**
- 擺放設備
- 移動設備
- 旋轉設備
- 刪除設備
- 複製貼上（整組設備＋管線視為單一操作）
- 設備配方變更

**CR-02 管線連接：**
- 新增管線（Phase 1 含自動生成的物流橋；Phase 2 起含自動生成的分流器 / 匯流器）
- 移動管線
- 複製管線
- 刪除管線
- 修改管線彎折點（Phase 1 僅限繪製中；Phase 3 支援放置後調整）

**CR-05 流程視角：**
- 新增流程配方節點
- 刪除流程配方節點
- 中間產物設定變更（生產 / 倉庫直取）

### 2.3 不納入歷史的操作

以下操作不進入歷史佇列（屬於視圖操作，非資料操作）：
- 畫布縮放 / 平移
- 視角切換（佈局 / 流程 / 並列）
- 選取 / 框選
- 左側面板展開 / 收合
- Flow Chart 節點位置調整（純視覺排版）

### 2.4 複合操作（Macro Command）

部分操作由多個子操作組成，應視為單一歷史項目，一次 Ctrl+Z 全部復原：

| 複合操作 | 包含的子操作 |
|----------|-------------|
| 複製貼上 | 擺放多台設備 + 新增多條管線 |
| 新增管線（含自動節點）| 新增管線 + 插入物流橋（Phase 2 起含分流器 / 匯流器） |
| 從流程視角導入設備 | 擺放多台設備 + 新增預設管線建議 |

---

## 3. 驗證方式

| 驗證項目 | 方法 |
|----------|------|
| 基本復原 | 擺放設備後 Ctrl+Z，確認設備消失 |
| 基本取消復原 | 復原後 Ctrl+Y，確認設備重新出現 |
| 多步復原 | 連續擺放 5 台設備，連續 Ctrl+Z 5 次，確認逐一消失 |
| 新操作清空 redo | 復原後執行新操作，確認 Ctrl+Y 無效 |
| 跨視角復原 | 在流程視角新增配方節點，切換至佈局視角後 Ctrl+Z，確認節點被復原 |
| 設備移動復原 | 移動設備後 Ctrl+Z，確認設備回到原位置 |
| 設備旋轉復原 | 旋轉設備後 Ctrl+Z，確認設備恢復原朝向 |
| 設備刪除復原 | 刪除設備後 Ctrl+Z，確認設備重新出現 |
| 設備配方變更復原 | 變更設備運行配方後 Ctrl+Z，確認恢復原配方 |
| 新增管線復原 | 新增一條不含自動節點的管線後 Ctrl+Z，確認管線消失 |
| 管線刪除復原 | 刪除管線後 Ctrl+Z，確認管線連同原有彎折點與自動節點重新出現 |
| 彎折點修改復原（Phase 3） | Phase 3 調整已放置管線彎折點後 Ctrl+Z，確認彎折點恢復原位置 |
| 流程配方節點刪除復原 | 刪除流程配方節點後 Ctrl+Z，確認節點重新出現 |
| 中間產物設定變更復原 | 變更中間產物設定（生產 / 倉庫直取）後 Ctrl+Z，確認恢復原設定 |
| 複合操作單次復原 | 新增含物流橋的管線，一次 Ctrl+Z 確認管線與物流橋同時消失 |
| 複合操作單次復原（Phase 2） | 新增含分流器的管線，一次 Ctrl+Z 確認管線與分流器同時消失 |
| 複製貼上復原 | 複製貼上一組設備，Ctrl+Z 確認整組同時消失 |
| 管線移動復原 | 移動已放置管線後 Ctrl+Z，確認管線回到原位置（含端點連接狀態） |
| 管線複製復原 | 複製一條管線後 Ctrl+Z，確認複製出的管線消失 |
| 流程視角導入設備復原 | 從流程視角一鍵導入設備，一次 Ctrl+Z 確認匯入的設備與預設管線建議同時消失 |
| 視圖操作不進歷史 | 縮放畫布後 Ctrl+Z，確認縮放不被復原（而是復原上一個資料操作）|
| 視角切換不進歷史 | 切換佈局 / 流程視角後 Ctrl+Z，確認視角不受影響（而是復原上一個資料操作）|
| 選取框選不進歷史 | 框選一組物件後 Ctrl+Z，確認框選狀態不受影響（而是復原上一個資料操作）|
| 面板收合不進歷史 | 收合左側面板後 Ctrl+Z，確認面板狀態不受影響（而是復原上一個資料操作）|
| Flow Chart 排版不進歷史 | 調整 Flow Chart 節點視覺位置後 Ctrl+Z，確認排版不被復原 |
| Session 清空 | 執行操作後重新整理頁面，確認 Ctrl+Z 無法復原（歷史已清空）|
