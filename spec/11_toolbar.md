## 1. 功能定位

畫面下方列出所有可用設備，使用與終末地相同的分類方式，以 Tab 切換不同類設備顯示。使用者可直接點選某設備，觸發 CR-01 的物件資訊面板顯示；也能在任意視角直接把設備拖曳到畫布上放置。

> 本文件內容自 `01_canvas_and_devices.md` 拆分而出（原 2.3「從工具列拿起」、5.3「下方設備工具列」、5.4 工具列快捷鍵列、部分驗證項目），細節待依 `00_top_spec.md` CR-11 的敘述持續補齊。

## 2. 功能詳細描述

### 2.1 從工具列拿起設備

1. 左鍵單擊工具列中的設備
2. 物件資訊面板更新顯示該設備資訊
3. 滑鼠進入「拿起設備」狀態，游標跟隨設備半透明預覽

拿起後的互動（Edge Scrolling、R 鍵旋轉、Esc 取消、放下等）與 CR-01 畫布拿起狀態共用同一套流程，見 `01_canvas_and_devices.md` 2.3 節。

### 2.2 拖曳擺放

使用者在任意視角都能直接拖動出來設備到畫面上放置（互動細節待補）。

### 2.3 中繼器顯示限制

中繼器不允許擺放，因此不列入工具列的設備面板中；判斷依據為 `DeviceDef.allowInBase` 欄位，定義見 `tmp_01_impl_notes.md`。

---

## 3. UI 規格

### 3.1 下方設備工具列

- 依 CR-01 `01_canvas_and_devices.md` 3.2 節設備分類，以 Tab 橫向切換顯示
- `allowInBase: false` 的設備（如中繼器）不允許擺放，自動從工具列隱藏
- 每個設備顯示：圖示、名稱
- 搜尋框可跨分類即時過濾

### 3.2 快捷鍵

| 快捷鍵 | 情境 | 功能 |
|--------|------|------|
| 左鍵單擊（工具列） | 任何時候 | 拿起設備 |

---

## 4. 驗證方式

| 驗證項目 | 方法 |
|----------|------|
| 工具列單擊拿起設備 | 點選工具列設備，確認物件資訊面板更新、游標顯示設備預覽 |
| 工具列拿起連續放置 | 放置後確認自動繼續拿起下一個相同設備 |
| 工具列 Tab 分類切換 | 點選各分類 Tab，確認只顯示該分類設備 |
| 搜尋跨分類過濾 | 輸入關鍵字，確認跨 Tab 即時過濾設備 |
| 中繼器不列入工具列 | 確認任何情況下，電力分類 Tab 中都不顯示中繼器 |
